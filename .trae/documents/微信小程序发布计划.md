## 三、发布流程步骤

### 阶段一：账号准备（1-3天）

**步骤1：注册小程序账号**
- 访问 https://mp.weixin.qq.com/
- 点击"立即注册" → 选择"小程序"
- 填写邮箱、密码等基本信息
- 完成邮箱验证

**步骤2：完成主体认证**
- 登录小程序后台
- 进入"设置" → "基本设置" → "主体信息"
- 选择认证类型：
  - **个人认证**：免费，功能受限（不能接入支付、部分接口受限）
  - **企业认证**：300元/年，功能完整
- 提交认证资料（身份证/营业执照等）
- 等待审核（通常1-3个工作日）

**步骤3：配置小程序信息**
- 设置小程序名称、头像、介绍
- 配置服务类目（建议选择：**工具-效率工具** 或 **生活服务-婚庆服务**）
- 添加开发者/体验者权限（如需团队协作）

### 阶段二：代码准备与测试（1天）

**步骤4：清理云开发相关代码**

由于改为纯本地运行，需要确保以下清理工作已完成：

1. **删除云开发初始化代码**（如存在）：
   - 检查 `miniprogram/app.js` 中是否有 `wx.cloud.init()`
   - 如有，请删除

2. **删除云函数文件夹**（可选）：
   - 项目中的 `cloudfunctions/` 文件夹在纯本地模式下不会被打包
   - 可以选择保留或删除

3. **更新 project.config.json**：
   - 移除 `cloudfunctionRoot` 配置（如不需要）

**步骤5：本地功能测试**

在微信开发者工具中进行全面测试：

| 测试项 | 测试内容 | 预期结果 |
|--------|----------|----------|
| 首次启动 | 删除本地缓存后重新进入 | 正常显示默认数据 |
| 任务管理 | 添加、完成、取消任务 | 状态正确保存 |
| 婚礼日期 | 设置婚礼日期 | 日期正确保存并显示倒计时 |
| 预算管理 | 添加预算项目 | 数据本地保存 |
| 宾客管理 | 添加宾客信息 | 数据本地保存 |
| 决策清单 | 添加决策事项 | 数据本地保存 |
| 数据持久化 | 关闭小程序后重新打开 | 数据不丢失 |

**步骤6：真机预览测试**
1. 在微信开发者工具中点击"预览"
2. 扫描二维码在真机上测试
3. 确认所有功能在真机上正常工作

### 阶段三：代码审核准备（0.5天）

**步骤7：代码自查**
- [ ] 检查所有页面是否能正常访问
- [ ] 检查所有功能是否正常运作
- [ ] 检查是否有console.log调试代码（建议清理或注释）
- [ ] 检查是否有敏感信息泄露
- [ ] 检查是否有未使用的代码文件

**步骤8：准备审核材料**
- 准备小程序截图（至少5张，展示主要功能）：
  - 首页（倒计时+任务概览）
  - 备婚指南页面
  - 我的婚礼页面
  - 任务清单页面
  - 个人中心页面
- 准备小程序功能说明（简要描述）

### 阶段四：提交审核（1-7天）

**步骤9：上传代码**
1. 在微信开发者工具中
2. 点击右上角"上传"按钮
3. 填写版本号（如：1.0.0）
4. 填写项目备注（如：备婚手帐首次发布）
5. 点击上传

**步骤10：提交审核**
1. 登录[小程序后台](https://mp.weixin.qq.com/)
2. 进入"管理" → "版本管理"
3. 找到"开发版本"，点击"提交审核"
4. 填写审核信息：
   - **功能页面**：选择首页（pages/index/index）
   - **标题**：备婚手帐-婚礼筹备助手
   - **标签**：婚礼、备婚、手帐、工具、倒计时
   - **备注说明**：
     ```
     备婚手帐是一款帮助新人筹备婚礼的工具类小程序。
     主要功能包括：
     1. 婚礼倒计时：显示距离婚礼的剩余天数
     2. 备婚任务清单：按阶段划分的备婚任务管理
     3. 预算管理：记录婚礼各项支出预算
     4. 宾客管理：管理婚礼宾客名单
     5. 决策清单：记录婚礼相关决策事项
     6. 灵感库：提供婚礼灵感参考
     
     所有数据均存储在本地，无需服务器和云开发。
     ```
5. 上传截图（5张以上）
6. 提交审核

**步骤11：等待审核**
- 审核时间：通常1-7个工作日
- 可在后台查看审核状态
- 如被驳回，根据反馈修改后重新提交

### 阶段五：发布上线（即时）

**步骤12：发布上线**
- 审核通过后，在后台点击"发布"
- 小程序正式上线，用户可搜索使用

## 五、注意事项

### 5.1 认证相关
- **个人认证**：免费，适合工具类小程序
  - 限制：不能使用微信支付、部分高级接口受限
  - 对于"备婚手帐"这类纯工具小程序，个人认证已足够
- **企业认证**：300元/年，功能完整，需要营业执照

### 5.2 代码审核常见驳回原因
1. **功能不完整**：确保所有功能都能正常使用
2. **内容违规**：确保内容符合微信小程序规范
3. **用户体验差**：确保界面美观、交互流畅
4. **隐私问题**：如涉及用户数据，需在隐私政策中说明数据仅本地存储
5. **类目不符**：确保选择的服务类目与小程序功能匹配

### 5.3 纯本地小程序的优势
- ✅ 无需服务器成本
- ✅ 无需云开发配置
- ✅ 审核更容易通过（无后端服务）
- ✅ 用户数据隐私性好（仅存储在用户设备）

### 5.4 纯本地小程序的局限
- ⚠️ 数据无法跨设备同步
- ⚠️ 用户换手机或清除缓存后数据丢失
- ⚠️ 无法实现社交功能（如分享、排行榜等）
